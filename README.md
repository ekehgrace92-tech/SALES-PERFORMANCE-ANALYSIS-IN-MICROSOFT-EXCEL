# SALES-PERFORMANCE-ANALYSIS-IN-MICROSOFT-EXCEL
An interactive Excel dashboard analyzing sales, profitability, customer performance, product categories, monthly trends, and geographic sales distribution to generate actionable business insights.
# PROJECT OVERVIEW
This project presents an interactive Excel dashboard designed to analyze sales and profitability performance.
# KEY ANALYSIS AREA
- Total Sales
- Total Profit
- Sales by Category
- Profit Trends Over Time
- Monthly Sales
- Top 5 Customers
- Sales by State
# KEY INSIGHTS
- Technology shows strong profit growth.
- Sales increased significantly toward November and December.
- Sales performance varied considerably by state.
- Overall profitability shows an upward trend.
  # TOOLS USED
  - Microsoft Excel
  - Pivot Tables
  - Pivot Charts
  - Data Visualization
  - Dashboard Design.
  # KEY PERFORMANCE INDICATORS
  - Total Sales
  - Total Profit
  - Total Customers.
  # BUSINESS OBJECTIVE
  The objective is to transform sales data into actionable insights that support business performance monitoring and decision-making.
